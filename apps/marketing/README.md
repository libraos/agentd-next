# Upstream's website

This folder is the source of upstream T3 Code's website. It comes with the code AgentD Next is built on and is retained to ease merging upstream changes.

It is not AgentD Next's website, and LibraOS does not deploy it.

- The download pages here describe upstream's product. Where they name the only official download site, they refer to T3 Code. AgentD Next installers are available from the [releases page](https://github.com/libraos/next/releases).
- The privacy policy, terms of service and security policy pages here are upstream's documents for upstream's product and services.

For AgentD Next:

- The End User Agreement shown in the app has the app's terms.
- [`LICENSE`](../../LICENSE) has the code's licence.
- [`SECURITY.md`](../../SECURITY.md) says how to report a security problem.
- The [product usage data page](../../docs/user/telemetry.md) describes the data practices it documents.
