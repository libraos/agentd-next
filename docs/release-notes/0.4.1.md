- **Install a plugin from a GitHub link.** In Settings → Plugins, paste a link to a repository, a plugin folder in it or its `catalog.json`; a plugin-folder link opens that plugin's install dialog. Private repositories are read through your GitHub connection after you confirm once; the token field stays as a fallback.
- **Sign in with GitHub** is on by default, through the LibraOS Next GitHub app. Already signed in with `gh auth login`? Next uses that.
- **Private plugin catalogues and developer mode** (load a plugin from a local folder), with a badge for where each plugin comes from: Official, an owner's private catalogue, or Local.
- **LibraOS Engine v0.1.24** inside.
