- **Buy LibraOS credits in the app.** With the LibraOS Gateway connected, your balance shows in the Gateway panel, Settings and the Usage page. Choose an amount, pay on Stripe in your browser, and the balance updates when you come back. When a Gateway agent runs out of credits, Next says so and offers Buy credits and Retry.
- **LibraOS plans in the app.** The plans your account can subscribe to show beside the balance, with Subscribe on Stripe in your browser. Plans appear as they become available.
- **Customize** replaces Plugins in the sidebar. It has three panes: Plugins, Connectors and Skills.
- **Connectors** lists the MCP servers of Claude Code and Codex. Turn one on or off, add one, or remove one, without editing the agent's files. Claude Code connectors are switched per project, as `/mcp` does.
- **Skills** lists each agent's skills. Read a skill's `SKILL.md`, and turn it on or off for Claude Code or Codex.
- **Plugins in Claude Code's format.** Install a Claude Code plugin folder or a `marketplace.json` catalogue. Its skills, commands, agents and hooks work in Claude Code, and its MCP servers reach Codex and OpenCode too. Plugins in the earlier format keep working.
- With a custom gateway, a long gateway name no longer cuts off the model name in the message box.
