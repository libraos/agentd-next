- **One-click LibraOS sign-in.** Sign in opens your browser with the code already filled in; approve there and Next returns with your balance shown and Continue ready. A new machine with no agents installed can start chatting with Pi · LibraOS right after approving.
- **A simpler welcome page.** LibraOS heads the agent list, followed by the agents you already use. Join a team moved to Settings.
- **Shorter names.** Gateway agents are named Claude Code · LibraOS, Codex · LibraOS, opencode · LibraOS and Pi · LibraOS; a custom gateway saved without a name is named after its host.
- **One LibraOS card in Settings → Providers** with your balance and plan, Buy credits and Plans. A key revoked or used up while Next runs now shows as such, with Reconnect or Buy credits.
- **Gateways behind your own certificate authority** work once that CA is in the system certificate store, without `NODE_EXTRA_CA_CERTS`. An untrusted certificate is reported as such instead of "Check your connection".
- **Custom gateways show their video, image and audio models** in the gateway's Models panel instead of dropping them.
- **Sharing & access is back** in Settings, along with scheduled tasks, triage, issues, pull requests and workflows.
- Cloud tasks tell you to install the LibraOS GitHub App, with an Install button. The Engine's MCP server shows as LibraOS Engine.
- Faster thread switching and streaming replies.
