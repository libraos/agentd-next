# LibraOS Next 0.3.0: AgentD Next installs move to it (libraos/agentd-core#1038)

AgentD Next 0.2.3 is offered LibraOS Next 0.3.0 as its update (analysis per platform:
[next-0.3-release](../design/next-0.3-release.md)). On Windows the installer now removes AgentD Next with
its own uninstaller, keeping its data; the deb replaces the `agentd-desktop` package instead of
installing beside it, which made the old app relaunch and offer the update again; the release notes end
with a short line the 0.2.3 update prompt shows first.

Upstream files changed:

- `scripts/build-desktop-artifact.ts`: deb `Conflicts` and `Replaces` on `agentd-desktop`.
- `scripts/build-desktop-artifact.test.ts`: expects them.
- `apps/desktop/resources/installer.nsh`: `removePreviousApp`, run from `customInstall`.
- `apps/desktop/package.json`: version 0.3.0.
- `.github/workflows/release.yml`: the AgentD Next paragraph per platform, and a closing notice line.
- `docs/user/updating.md`, `docs/user/install.md`: what an AgentD Next install does per platform; the
  desktop app has an update feed.
